# VPN Configuration

> This directory is intentionally empty.
>
> Remote access is handled by **Tailscale** or **Cloudflare Tunnel**
> (not a traditional VPN like WireGuard or OpenVPN).
>
> - **Tailscale** runs on the Docker VM host and provides encrypted
>   mesh networking to access services from anywhere.
> - **Cloudflare Tunnel** can be used as an alternative to port forwarding
>   (no open ports on your router).
>
> This directory exists as a placeholder for future VPN configuration
> (e.g., WireGuard configs if you decide to run your own VPN server).
>
> If you don't plan to use it, you can safely delete this directory.
