# DNS Configuration

> This directory is intentionally empty.
>
> DNS is handled by **Pi-hole** running as a Docker container.
> The Pi-hole configuration lives in `configs/docker/pihole/`.
>
> This directory exists as a placeholder for any future non-Docker DNS
> configuration (e.g., BIND zone files, custom dnsmasq configs that run
> outside of Docker).
>
> If you don't plan to use it, you can safely delete this directory.
